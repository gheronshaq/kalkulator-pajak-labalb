# Kalkulator Pajak (PyQt6)

Aplikasi kalkulator pajak berbasis **Python** dan **PyQt6**.  

---

## 📁 Struktur Project
kalkulator-pajak-labalb/
├── resources/ # Asset pendukung (icon, gambar, dll)
├── src/ # Source code utama aplikasi
├── tests/ # File testing (opsional)
├── requirements.txt # Daftar dependency Python
├── README.md

---

## 🔧 Persiapan Sebelum Clone
Pastikan sudah terinstall:
- Python **3.9 atau lebih baru**
- Git
- Code Editor (disarankan **Visual Studio Code**)

## 📥 Clone Repository
git clone https://github.com/nama-org/kalkulator-pajak-labalb.git
cd kalkulator-pajak-labalb

## ⚙️ Membuat Virtual Environment
python -m venv venv

## Aktifkan virtual environment:
Windows:
venv\Scripts\activate

mac/linux:
source venv/bin/activate

## 📦 Install Dependency
pip install -r requirements.txt

Jika PyQt6 belum terinstall:
pip install PyQt6

## Run Program
- cd src (masuk ke folder src terlebih dahulu)
- python main.py
